# 토스 동선 관찰 요약

출처: 사용자가 제공한 「토스 앱 사용자 동선 분석 보고서」, 2026-11-09, 5쪽.
보고서 기록 환경: Windows 11, Galaxy S23(Android 16), ADB 1.0.41, @mobilenext/mobile-mcp 1.0.16.
이 스킬의 작성자는 해당 기기를 직접 조작한 것이 아니라 제공된 보고서를 읽었다.

## 관찰된 구조
홈·혜택·쇼핑·증권을 탐색했다. 하단에는 전체를 포함해 5개 탭이 있다.
홈에 상태 요약과 빠른 행동, 최근 항목을 배치한다. 카드에 주요 행동 하나를 두고 짧은 문구로 안내한다.
쇼핑에서는 검색·카테고리·장바구니와 쿠폰 팝업 진입까지 확인했다.

## 근거의 한계
전체 탭, 송금 내부 단계, 상품 상세부터 결제까지는 직접 기록되지 않았다.
송금의 받는 사람 → 금액 → 확인 → 인증은 일반적인 단계 추론이다.
증권에서 보안 경고 후 앱이 종료되었고 우회하지 않았다.
다크 모드는 관찰 환경의 상태이며 모든 앱의 기본값이라는 결론은 내릴 수 없다.
허위 긴급성이나 할인·개인화 데이터를 만들어서는 안 된다.

## 자연석 쇼핑 구현 기록
브랜드: 온석. 크림색/녹색을 유지한다.
탭: 홈 / 상품 / 찜 / 장바구니 / 전체.
상품 데이터와 일러스트, 가격은 예시이며 실제 결제·주문 접수는 연결되어 있지 않다.
찜·장바구니·최근 본 상품·홈 설정은 브라우저 로컬에 보관하며 계정 간 동기화되지 않는다.
외부 판매 전에는 실제 상품, 사업자·연락처, 배송·반품 정책, 결제 연동이 필요하다.
