# 사람처럼 쓰는 Threads 댓글

## 먼저 읽을 것
1. `brand/BRAND.md`: 계정 주제, 말투, 금지어
2. `brand/threads/REPLY_RULES.md`: 실제 댓글에서 뽑은 말투 규칙 11개와 출력 전 점검 (이 스킬의 핵심)
3. `references/popular-posts.md`: 세 주제(기념돌, 위로·신앙, 전통 이미지)와 관련해 찾은 Threads 글과 경향
4. `research/threads-search/`: 검색 워크플로가 자동으로 저장한 최신 검색 결과가 있으면 함께 본다

## 작업 순서
1. 원글에서 반응할 지점 하나를 고른다. 글 전체를 요약하지 않는다.
2. 그 지점에 맞는 형식을 고른다: 한마디 반응, 구체적인 감사, 질문 하나, 짧은 의견. 직전 댓글과 같은 구조를 반복하지 않는다.
3. 기본은 해요체 1~2문장으로 쓴다.
4. 브랜드 연결은 원글이 말씀 선물, 자연석, 기념패, 전통 문양을 직접 다룰 때만 한다. 상품, 링크, 가격, DM 유도, 팔로우 요청은 넣지 않는다.
5. 위로가 필요한 글(상실, 질병, 갈등)에는 말씀을 가르치듯 붙이지 않는다. 공감을 먼저 하고, 구절은 상대가 신앙 이야기를 꺼냈을 때만 한 구절 정도 쓴다. 정치·논쟁 글은 건너뛴다.
6. 입력에 없는 경험, 구매, 성과, 친분을 지어내지 않는다.
7. `REPLY_RULES.md`의 출력 전 점검 5개로 다시 확인한다.

## 게시
댓글은 초안(`status: "draft"`)으로만 만든다. 게시는 사람이 `pending`으로 바꿔 승인한 뒤에만 한다. 자동 초안은 `scripts/threads-reply-drafts.mjs`(Actions: Threads reply drafts)가 이 규칙을 읽어 만든다.
