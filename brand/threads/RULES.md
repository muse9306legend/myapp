# Threads 글 규칙

- 길이: 250~450자 (Threads 최대 500자)
- 첫 줄: 궁금증을 만드는 질문이나 반전 한 줄
- 본문: 하나의 글에는 하나의 메시지만
- 줄바꿈을 자주 해서 모바일에서 읽기 쉽게
- 마지막 줄: 댓글을 부르는 질문 또는 공감 한 줄
- 해시태그는 쓰지 않거나 1개만
- 하루에 올리는 글끼리는 형식(경험담 / 팁 목록 / 질문 / 반전 썰)을 서로 다르게

## 주제 아이디어 뽑는 법
요즘 관심 가는 토픽을 내 주제와 연결해서, 같은 방식이나 메커니즘의 변형은
새로운 아이디어로 세지 않고 서로 다른 유형으로만 고른다.
