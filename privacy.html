개인정보처리방침

커밍스톤 Threads 자동화 · 시행일 2026년 11월 22일

트윈루지컴퍼니(이하 "회사")는 커밍스톤 브랜드의 Threads 계정을 운영하기 위해 Meta의 Threads API를 사용하는 앱 "쓰레드연결2"(이하 "앱")를 운영합니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 앱의 목적

앱은 회사가 직접 소유한 Threads 계정(@comingstone.kr)의 게시물을 예약 게시하고, 그 게시물의 답글과 성과를 확인하며, 공개 게시물을 키워드로 검색해 콘텐츠 기획에 참고하는 내부 운영 도구입니다. 일반 사용자의 가입이나 로그인을 받지 않습니다.

2. 처리하는 정보

  • 회사 Threads 계정의 프로필 정보(사용자 이름, ID)
  • 회사가 작성·게시한 글의 내용, 게시 시각, 링크, 조회수·좋아요 등 성과 지표
  • 회사 게시물에 달린 답글의 내용과 작성자 사용자 이름 (답글 확인·응답 목적)
  • 키워드 검색으로 조회한 공개 게시물의 내용과 링크 (콘텐츠 기획 참고 목적)

앱은 비밀번호, 결제 정보, 연락처 등 민감한 개인정보를 수집하지 않습니다.

3. 이용 목적

  • 회사 계정의 게시물 작성·예약·게시
  • 회사 게시물에 달린 답글 확인 및 응답
  • 게시물 성과 분석과 콘텐츠 개선

수집한 정보는 광고 타기팅, 판매, 제3자 마케팅에 사용하지 않습니다.

4. 보관과 저장 위치

게시 예약 목록과 게시 결과는 회사가 관리하는 GitHub 저장소에 저장됩니다. 답글과 검색 결과는 확인·응답에 필요한 기간 동안만 보관하며, 목적을 달성하면 삭제합니다. Threads API 접근 토큰은 GitHub의 암호화된 비밀 저장소(Secrets)에만 보관합니다.

5. 외부 서비스 이용

  • Meta Threads API: 게시, 답글, 성과, 검색 기능 제공
  • GitHub: 자동화 실행(GitHub Actions)과 데이터 저장
  • Anthropic Claude API: 회사 게시물 초안 작성. 회사의 브랜드 설명서와 최근 게시물 내용이 전달될 수 있으며, 다른 사람의 답글이나 개인정보는 전달하지 않습니다.

6. 정보 삭제 요청

본인과 관련된 정보(예: 회사 게시물에 남긴 답글)의 삭제를 원하시면 데이터 삭제 안내에 따라 요청해 주세요. 확인 후 30일 이내에 삭제하고 결과를 알려드립니다.

7. 문의

개인정보 관련 문의는 Threads @comingstone.kr 계정의 DM으로 보내 주세요.

8. 방침 변경

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.
